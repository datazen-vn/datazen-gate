# market-gate (dz-gate)

Cổng paywall độc lập cho app có sẵn gắn thuê bao DataZen: đứng trước app của dev, nhận diện khách, hỏi hub quyền dùng, rồi cho qua / chuyển tới trang thanh toán.

Trạng thái: đang xây (repo private tới khi E2E lát 2 xanh). Hợp đồng hành vi: bộ ca `gate-v1` trong repo `meta` (`contracts/conformance/gate-v1/`), dùng chung với `@datazen/sdk/gate`.
